# University Management System

The University Management System is a desktop application developed using C# and Windows Forms. The system is designed to help manage university students, teachers, courses, grades, and communication in an organized and user-friendly environment.

The application works offline and uses local file storage to save and manage the system's data. It does not require an internet connection, making it suitable for use on computers within a university or educational environment.

## Main Features
### Student Management: 
The system allows administrators to register students and manage their information, including personal details and student photos.
### Teacher Management: 
Teachers can be added and managed by the administrator, with access to the features related to their teaching responsibilities.
### Course Registration: 
The administrator has access to the registration system, where they can add courses and assign teachers to courses and students.
### Marks Management: 
Teachers can enter and manage students' marks. Students can view their grades through their accounts.
Student Email System: Teachers can send messages or emails to students through the system. Students can access the email page to read messages sent by their teachers.
### Student Photos: 
Student profiles can include uploaded photos, making it easier to identify and manage students.
### User Roles: 
The system provides different access levels for administrators, teachers, and students, ensuring that each user can access the appropriate features.
### Offline File Storage: 
Information and uploaded files are stored locally on the computer rather than relying on an online database or internet connection.
### Windows Forms Interface: 
All system interfaces are developed using C# Windows Forms, providing a desktop-based graphical user interface that is simple and easy to navigate.
# User Roles
### Administrator:
The administrator has the highest level of access. They can register students, add teachers, create and upload courses, and manage the overall university system.

### Teacher:
Teachers can access their assigned courses, manage student marks, and send emails or messages to students.

### Student:
Students can access their personal information, view their marks, check their courses, view their uploaded photo, and read emails or messages sent by teachers.

# Project Goal

The main goal of the University Management System is to provide a simple, offline, and organized solution for managing university information. By combining student management, teacher management, course registration, grades, communication, and local file storage into one Windows Forms application, the system reduces the need for separate manual processes and provides users with an easy-to-use desktop platform.
